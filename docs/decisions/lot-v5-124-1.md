## A731 — Le chemin d'une image Notion admet des parenthèses

**Le défaut.** Notion nomme le dossier d'images d'après la page (tronqué) et encode espaces et accents, PAS les
parenthèses. `NOTION_IMG` (A562, bornée en A670) lisait le chemin en `[^)\s]+` : il s'arrêtait à la « ) » de
`(DT1,%20DT2)`. Le chemin cherché dans l'archive était `…(DT1, DT2` — introuvable, image comptée « absente », et
`%20hypogly/image%201.png)` restait dans le texte.

**Décision.**
- Un segment de chemin est une suite de caractères sans espace ni parenthèse, de groupes `(…)` ÉQUILIBRÉS (comme
  CommonMark), ou d'une `(` seule — Notion tronque le nom du dossier, la coupe peut tomber dans une parenthèse.
- La regex reste LINÉAIRE (A670) : segments sans espace, la première alternative exclut `(` et `)`, tout est borné
  (`{0,300}`, `{1,2000}`, `{0,40}`). Témoin de durée dans `tests.html` (A731).
- Même lecture pour le lien vers une autre page `.md` (son texte seul est gardé) : un titre à parenthèses y laissait
  le lien brut.

**Limite connue.** Une `(` tronquée suivie, sur la même ligne, d'un texte entre parenthèses après une espace : le
groupe équilibré l'emporte, le chemin est faux, l'image est dite absente (comme avant). Notion pose ses images seules
sur leur ligne ; on ne consulte pas l'archive pour départager.

**Forme écartée** : tout caractère non blanc jusqu'à la dernière « ) » — deux images sur une ligne (`![a](x) ![b](y)`)
se fondraient en un seul chemin.
