# Lot v5.128 — Exporter avec ou sans les fichiers joints (A751)

**Origine.** L'auteur : « l'export de protocole/aide n'inclut pas les images ni les PDF ? », capture du menu
« Exporter le protocole (.json) » d'un protocole illustré, « n'exporte que le json » ; demande : « laisser le choix
d'exporter avec ou sans les fichiers joints ». Aucun changement de modèle ni de serveur ; format d'export inchangé.

## A751 — La question est toujours posée, et « Sans » allège vraiment

**Mesuré** (sonde Chromium, depuis la lecture, l'éditeur et la sélection de l'accueil). Les images étaient TOUJOURS
dans le fichier (`images[].data`, `b.image` : données en ligne), et les PDF dans le .zip quand on le choisissait.
Mais (1) la question n'apparaissait que s'il y avait des PDF : un protocole illustré sans PDF partait en .json sans un
mot, images invisibles dans le fichier — d'où « n'exporte que le json » ; (2) l'option « sans » ne retirait que les PDF ;
(3) les PDF étaient lus dans IndexedDB APRÈS le tap : sur iPhone, application installée, `dlBlob` passe par la
feuille de partage, qui exige un geste encore actif — consommé par ces lectures, l'envoi retombait sur un lien qui
ne s'ouvre pas, et l'archive pouvait ne jamais arriver ; (4) le libellé « (.json) » était faux dès qu'un .zip sort.

**Décision.**
- `exportData` demande « Avec les fichiers joints » / « Sans les fichiers joints » dès qu'il y a une image (galerie
  ou image de bloc, dédoublonnées) ou un document, et dit combien. Sans fichier joint : pas de question.
- **Avec** : comme avant — .json avec ses images, ou .zip (`donnees.json` + `documents/<id>.pdf`) s'il y a des PDF.
- **Sans** : `exportLeger` (pure, testée) retire images, image de bloc, documents, et dans le texte rédigé les lignes
  `![…](img:ID)` et les liens `[texte](att:ID)` (le texte reste) : rien ne pend à l'import (ni image introuvable,
  ni rangée « △ à télécharger » d'un document qui n'arrivera jamais).
- Le .zip est construit AVANT la question : le tap appelle `dlBlob` sans plus rien attendre.
- Menus : « Exporter l’aide » / « Exporter le protocole », sous-titre « avec ou sans les fichiers joints ».

**Formes écartées.** Sortir les images comme fichiers séparés dans le .zip : le fichier ne serait plus réimportable
tel quel (le modèle porte les images en ligne) — rien n'y gagnerait. Garder la question réservée aux PDF : c'est le
défaut signalé.

**Garde-fou.** `tests.html` : « A751 : export « sans les fichiers joints » » (images, image de bloc, documents, ligne
d'image et lien de document retirés, texte gardé, source intacte).
