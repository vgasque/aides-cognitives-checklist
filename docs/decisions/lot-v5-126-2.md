# Lot v5.126.2 — Deux correctifs signalés à l'usage (A741-A742)

**Origine.** Deux signalements de l'auteur le même jour : le code de session reconnu à tort (A741), le surlignage
d'un PDF perdu après un zoom (A742). Pour le premier : taper « ACR réfrac » dans la recherche affichait « Code de session reconnu ·
Rejoindre ACRR-FRAC ». Correctif ; aucun changement de modèle ni de serveur. Amende J89 sur un point.

## A741 — La saisie doit être un code tel qu'on l'écrit

**Cause.** `homeJoinHtml` passait la recherche par `shareCodeNorm`, qui retire TOUT ce qui n'est ni A-Z ni 0-9. C'est
voulu dans le champ de l'écran « Rejoindre », où l'on ne tape qu'un code. Dans la recherche, il soudait deux mots et
avalait la lettre accentuée : « ACR réfrac » → `ACRRFRAC`, huit caractères de l'alphabet des codes. J89 tenait la
collision pour « nulle en pratique » ; elle ne l'est pas dès qu'on tape deux mots.

**Décision** (`qJoinCode`). La recherche n'est lue comme un code que si la saisie entière a sa forme : 8 caractères
A-Z/0-9 d'un seul tenant, ou 4 + 4 séparés par UN tiret ou UNE espace ; aucun accent, rien avant ni après. Puis le
contrôle de toujours (`shareCodeValid` : alphabet de 32 symboles, sans 0/1/I/O).

**Ce qui reste, et c'est assumé.** Un mot de 8 lettres toutes dans l'alphabet des codes (« fentanyl ») affiche encore
la ligne : un code n'a pas d'autre signature (une fois sur dix il ne porte aucun chiffre). La règle de J89 tient pour
ce cas : la ligne s'AJOUTE aux résultats, elle ne les remplace pas.

**Garde-fous.** `tests.html` (trois témoins A741) ; `audit-partage` garde la ligne sur un vrai code.

## A742 — Dans un PDF, le surlignage et les liens reviennent après un zoom aller-retour

**Signalé.** « Quand je zoome-dézoome sur un PDF avec des mots surlignés, le surlignage disparaît. »

**Cause.** Un zoom retire les calques posés au pixel — surlignage et liens (`pdfApplyScale`, A554) — et compte sur le
NOUVEAU rendu de la page pour les reposer. Revenu à l'échelle déjà rendue avant que le rendu intermédiaire ait
abouti (zoom +, puis −), il n'y a pas de nouveau rendu : `renderPdfPage` sortait sur « déjà rendue à cette
échelle », et les calques ne revenaient plus. Les liens cliquables du document partaient avec.

**Décision.** Chaque page note l'échelle à laquelle ses calques sont posés (`s.ovW`, remise à zéro par le zoom). Une
page déjà rendue à l'échelle courante dont les calques manquent les repose (`pdfPaintHl`, `pdfPaintLinks`) sans
redessiner la page.

**Garde-fou.** `audit-pdfsearch`, « zoom + puis − : le surlignage revient, à sa place » — vérifié capable
d'échouer (correctif neutralisé → rouge).
